# Spatial World Foundation

This document defines the metric, seeded spatial backend for the current main island and the living terrestrial ecology that now runs on top of it.

## Canonical world

`src/data/mainWorldAreas.ts` is the lifecycle registry. Only the ten `MAIN_WORLD_AREA_IDS` are active macro regions. Every other entry in `AREAS_DATABASE` is legacy/archive data; old redirect aliases remain only for save/migration compatibility.

`src/data/poiTerritories.ts` remains the authored source of truth for macro-region shape. Procedural generation changes the local wilderness inside those regions, not the recognizable macro map.

## Physical scale

The island is calibrated to exactly **120 km² of land**. The source raster is 1672 × 941. Measuring the combined authored polygons while preserving raster aspect ratio produces a metric envelope of approximately **17.81 km × 10.02 km**; land occupies about **67.23%** of that rectangle.

Region area, centroid, bounds and area share therefore come from geometry rather than balance constants.

## One persistent world seed

`buildingSimulation.worldSeed` is the root world DNA for a campaign. It is persisted in save data and regenerated by `resetGame()` for a new run.

- same seed + same generation versions reproduces the same world;
- a new campaign receives a new seed;
- construction, terrain and ecology share the same root seed;
- most static terrain/ecology can be reconstructed instead of serialized verbatim.

`src/simulation/spatial/worldGeneration.ts` composes the generated spatial world.

## Spatial hierarchy

```text
Main Island — 120 km²
  -> Macro Region — 10 authored polygons
    -> Habitat Patch — seeded ~600 m lattice clipped to land
      -> Terrain + hydrology
      -> Per-seed Local Site pool
        -> Local Site instances + functional/resource semantics
      -> Living flora community
        -> Pollination / production / succession / plant biomass
      -> Living insect community
        -> Pollinators / herbivores / decomposers / aquatic larvae / prey biomass
      -> Terrestrial fauna cohorts
        -> Shared feeding / drinking / refuge competition
      -> Spatial predator cohorts
        -> Search -> encounter -> attack -> kill -> carrion
      -> Shared material budget
        -> Plant foods / accessible insects / carrion / fresh water
      -> Future exact trails / barriers / crossings / local encounter spaces
```

The macro map stays stable while patch geometry, terrain, Local Site vocabulary and ecology vary by campaign seed.

## Procedural habitat and terrain

`src/simulation/spatial/habitatPatches.ts` uses a nominal 600 m lattice whose global origin is shifted by the world seed before clipping against the fixed macro polygons. Different seeds therefore produce different local patch boundaries, centroids and IDs while conserving the same 120 km² land area.

Every patch has deterministic correlated elevation, slope, roughness, wetness, drainage, canopy/cover/forage/aquatic suitability, movement impedance, habitat tags and terrain tags.

## Generated hydrology

`src/simulation/spatial/terrainHydrology.ts` derives drainage from generated elevation. Patches route flow downhill where possible; upstream catchment accumulates and combines with wetness/aquatic suitability to classify seasonal streams, streams, rivers and wetland channels.

This is patch-scale water topology, not yet a rendered river spline.

## Procedural Local Sites

`src/simulation/spatial/localSiteCatalog.ts` defines **70 natural Local Site archetypes** plus three required landmarks. The catalog spans water/hydrology, terrain/geology, vegetation/resources, wildlife-use, coastal and disturbance families.

`localSiteGeneration.ts` scores archetypes against generated terrain/hydrology, excludes unsupported types, applies deterministic category quotas and seed affinity, then places instances only on locally suitable patches.

Plane Wreck, Limestone Cavern and Ruin Complex remain guaranteed exactly once. Older authored concepts such as Medicinal Glade, Kapok Grove, Wildlife Nest, Clay Pit and Jungle Trail survive as Local Site vocabulary rather than macro regions.

### Functional semantics

`localSiteProfiles.ts` gives all 73 Local Site types machine-readable semantics:

- player activities: water gathering, foraging, medicine, materials, fuel, fishing, hunting, trapping, salvage, shelter, camp, crossing, climbing, surveying and cave exploration;
- gameplay effects: movement, navigation, shelter, camp quality, hazard and visibility;
- ecology effects: forage, cover, water, breeding habitat, prey refuge, predator opportunity, aquatic nursery, decomposition and disturbance sensitivity;
- resource opportunities: resource family, abundance, renewability, seasonality, extraction impact and item mappings where available.

`aggregateLocalSiteInfluenceByPatch()` exposes these effects to the spatial ecosystem without hardcoding site names into fauna/flora logic.

## Dynamic player-facing Local Site resources

`localSiteResourceSimulation.ts` gives repeatable player-facing Local Site resources dynamic capacity, stock, condition and depletion pressure. It uses a 10% ecological reserve floor and critical-state hysteresis rather than a universal hourly respawn timer.

Recovery families include renewable biomass, geological flux, flowing water, episodic deposits, population-backed resources and salvage exposure.

This Local Site harvesting state is still separate from the authoritative patch material budget. That bridge is intentionally deferred until extraction can be unified without double-counting resources between player gathering and wildlife.

## Authoritative terrestrial food web

The metric patch world now owns the live terrestrial ecology. `GameState.spatialFaunaSystem` contains prey/herbivore/omnivore cohorts plus nested living flora, insects and predators.

The old BuildGrid/subarea terrestrial fauna, predator and long-run balance systems remain as compatibility/regression code but are **not ticked by `simEngine.ts`**. The old subarea flora still runs temporarily because existing UI/resource readers depend on it. Aquatic ecology remains a separate runtime for now.

Generated fauna metadata explicitly reports:

- `legacyRuntimeSpeciesCount = 0`;
- seven historical species remain only as `legacyCatalogBridgeSpeciesCount`, reusing authored life-history data without owning a second live population.

The whole trophic interaction layer has its own `interactionVersion`. Saves from the pre-migration spatial-fauna runtime are deterministically regenerated from the persistent world seed instead of carrying old anonymous resource pools into the new food web.

## Terrestrial fauna

`src/data/spatialFauna.ts` tracks **24 terrestrial non-predator species** spanning large herbivores/omnivores, small mammals, ground/canopy birds, bats, reptiles, amphibians and large invertebrates.

Patch carrying capacity derives from:

```text
real patch area
× prime-habitat density
× generated suitability
× macro-region affinity
× Local Site ecology
```

Counts are aggregate cohorts, not one runtime object per animal. Each occupied patch stores:

```text
[juveniles, adults, old, condition, stressDays]
```

The deterministic census remains:

- `spatial-fauna-alpha`: **23/24 species, 49,347 initial individuals, K 66,193**;
- `spatial-fauna-beta`: **23/24 species, 46,438 initial individuals, K 65,472**.

Fauna-only state starts around 282 KiB with roughly 4,700 occupied cohorts. The cohort runtime handles maturation, aging, mortality, reproduction, condition/stress and adjacency/cross-region dispersal.

## Living flora: small to large

`src/data/spatialFlora.ts` contains **40+ tracked flora taxa/guilds** across thirteen structural strata:

- emergent, canopy, subcanopy and understory trees;
- shrubs, herbs and groundcover;
- ferns;
- vines/lianas;
- epiphytes;
- reeds/sedges;
- mangroves;
- aquatic vegetation.

Each definition has habitat/region affinity, growth strategy, disturbance tolerance, seed/propagule dispersal and explicit ecological roles such as canopy structure, fruit/seed/browse/root/ground food, timber, fiber, medicine, nectar, pollinator host, insect host, nitrogen cycling, erosion/bank stabilization, wetland structure, refuge, succession pioneer and old-growth indicator.

Persistent patch state is compact:

```text
[standing biomass kg, propagule reserve, condition, succession age days]
```

`spatialFloraRuntime.ts` owns carrying biomass, growth, turnover, colonization/local extirpation and primary production. Fruit and seed output responds to pollination. Fauna consumption damages the corresponding living flora state.

### Flora owns plant renewal

The authoritative trophic material pass no longer uses census K as a daily plant-production floor. Plant-food renewal is driven mainly by current living flora biomass, condition, season and pollination. A small background term represents untracked seedlings, cryptogams and minor taxa, but cannot guarantee K support by itself.

A regression explicitly zeros plant stocks in two identical worlds, removes flora biomass from one, and requires the living-flora world to recover materially more food.

## Insects as a living trophic layer

`src/data/spatialInsects.ts` adds **20+ tracked insect taxa/guilds** across twelve functional guilds:

- pollinators;
- folivores;
- frugivores;
- seed feeders;
- wood borers;
- detritivores;
- dung feeders;
- carrion feeders;
- fungivores;
- predatory insects;
- blood feeders;
- aquatic larvae.

Suitability depends on habitat, hydrology, region, substrate and living flora host biomass. Insects are not just a scalar food bonus: pollination changes fruit/seed output, herbivorous guilds damage flora, and detritivore/termite/dung/carrion guilds contribute decomposition/nutrient effects.

Persistent insect patch state is:

```text
[live biomass kg, egg/larval/refugial recruitment reserve, condition]
```

Many tracked birds, bats, reptiles, amphibians and small mammals rely heavily on insects. Fauna consumes actual **accessible living insect biomass**. The protected recruitment reserve is not immediately edible and provides recovery after severe visible depletion.

One canonical accessible-biomass rule is shared by pool synchronization and consumption, avoiding a duplicate anonymous insect stock.

## Spatial predators

Five terrestrial predator definitions now live on the same patch world. Predator state includes age structure, condition and food reserve.

The daily hunt loop is spatial and prey-backed:

```text
home-range search
-> local prey abundance / refuge / predator opportunity
-> encounter
-> attack / kill
-> subtract heads from actual prey cohort
-> replenish predator reserve
-> add unused kill biomass to carrion
```

Poor hunting/reserve affects predator condition, mortality and movement. Predators are therefore no longer an omniscient legacy macro-region layer.

## Shared material budget

Each patch persists one compact material tuple for:

- fruit;
- seeds;
- browse;
- ground vegetation;
- roots/tubers;
- accessible insects;
- aquatic plants;
- carrion;
- fresh water.

Capacity remains area-scaled:

```text
patch capacity
= patch area km²
× standing crop / km²
× habitat / hydrology / Local Site potential
```

The lower-level capacity calibration currently measures about **67.93–68.25 million kg** of total standing food across the 120 km² island, with a minimum patch standing-food density around **310k–345k kg/km²**. Those numbers are **capacity/calibration**, not the authoritative daily production rate.

The older neutral-production model (~646–652k kg/day, versus ~3.0 t/day tracked census-K demand) remains useful as a consistency/scarcity regression. The live trophic pass does **not** grant that neutral rate or a K-based production floor as free food.

Active renewal owners are now:

- plant foods: living spatial flora + a small untracked-background term;
- insects: living insect communities;
- carrion: mortality/predation events minus decay;
- fresh water: hydrology/recharge;
- consumption: all co-located fauna share the same stocks.

Material shortage changes persistent condition/stress before demographic effects. Food/water niche pressure remains diagnostic when conserved stocks own scarcity; refuge remains an active shared-space constraint.

## Authoritative daily order

`spatialFaunaEcosystemRuntime.ts` resolves one terrestrial day in causal order:

```text
1. living flora growth / succession / production
2. insect growth / recruitment
3. insect functional effects on flora
4. shared material recovery + fauna feeding/drinking
5. refresh flora/insect telemetry after consumption
6. shared refuge/niche competition
7. fauna demography / dispersal
8. predator search -> encounter -> kill -> carrion
9. combined telemetry/history
```

This keeps material ownership causal and prevents food/water scarcity from being penalized twice.

## Travel foundation

`spatialTravel.ts` still uses lightweight generated patch adjacency and Dijkstra estimates. Existing authored expedition timing remains live gameplay data until exact terrain passability, trail networks, barriers, river crossings, weather/load/fatigue and route validation migrate onto spatial topology.

## Compatibility boundary and next phases

The terrestrial population migration is complete enough that there is one live spatial terrestrial food web. Remaining cross-system work is deliberately separate:

1. unify player gathering and Local Site harvesting with the same patch material budget, preventing humans and wildlife from extracting duplicate resources;
2. migrate aquatic populations onto generated hydrology where useful;
3. replace centroid-neighbor travel with exact passability, trails, barriers and seasonal crossings;
4. strengthen selected fauna behavior into explicit feeding/drinking/refuge/breeding site choice where gameplay needs it;
5. materialize only locally encountered groups/individuals for encounter gameplay/UI;
6. retire old subarea flora after all player-facing readers use spatial flora.

## Reproducibility contract

1. same seed + same generation/runtime versions reproduces the same spatial world and deterministic aggregate ecology;
2. different seeds materially change local terrain, Local Site pools and spatial population distribution while preserving the authored macro map;
3. patch/resource scale derives from real metric area and habitat;
4. fauna patch/region allocations exactly conserve island K and starting headcount;
5. all fauna in a patch draw from the same material stocks;
6. plant renewal is owned by living flora rather than a K food floor;
7. insect food is owned by living accessible insect biomass with protected recruitment reserve;
8. predator kills remove actual prey cohorts and create carrion from unused biomass;
9. shared niche/refuge competition responds to local overload without double-counting conserved food/water scarcity;
10. old terrestrial fauna/predator code cannot create a second live population in the game loop.
